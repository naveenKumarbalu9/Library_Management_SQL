# Library Management System using SQL

## 📌 Project Description

The **Library Management System** is a SQL-based project designed to manage and analyze library operations. It handles information about books, members, authors, borrowing records, and book returns using a relational database.

The project demonstrates practical SQL concepts through real-world library management scenarios.

## 🚀 Features

* Manage books and authors
* Manage library members
* Track book borrowing and returns
* Find available and borrowed books
* Analyze member borrowing activity
* Identify popular books
* Calculate overdue books
* Generate library reports
